# World Models Thesis


The repository is organized as an [Obsidian](https://obsidian.md/) vault with linked literature notes, paper summaries, and supporting materials. It is designed for literature synthesis and incremental thesis writing.

---

## The Goal of this Thesis

> *The objective of this thesis is to develop an end-to-end pipeline that optimizes a given chess engine based on specific hardware constraints. By applying compression techniques such as pruning and quantization, the framework aims to significantly reduce the model's footprint while preserving its original playing performance.*
